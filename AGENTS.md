# PixelPin — Agent Guidelines & Skills

## Active Skills Framework

This project incorporates two specialized agent skill frameworks:

### 1. Hallmark (`.agents/skills/hallmark`)
Design skill for interfaces that look made, not generated.
- **The Floor**: Tokenized `:root` colors and typography, no unstyled elements, high-craft visual hierarchy, responsive viewports, no invented metrics or slop.
- **Job-Driven Layouts**: Form follows real user intent and concrete material rather than generic boilerplates.
- **Craft Details**: Subtle border treatments, high-density layouts, accessible `:focus-visible`, and reduced-motion support.

### 2. Superpowers (`.agents/skills/*`)
Structured software engineering workflows:
- `brainstorming`: Explore edge cases, user experience, and architecture before implementation.
- `writing-plans` & `executing-plans`: Break complex tasks into structured, batched milestones.
- `systematic-debugging`: Investigate root causes systematically before modifying code.
- `test-driven-development`: Ensure critical business logic is validated and covered.
- `verification-before-completion`: Verify end-to-end functionality across web and mobile before concluding tasks.
